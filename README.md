# Linux Server Hardening Project

## 📌 Overview
This project demonstrates Linux system administration skills by setting up a secure server environment with proper user management, SSH hardening, firewall configuration, and Apache web server deployment.

---

## 🎯 Objectives
- Create and manage users with proper permissions  
- Secure SSH access  
- Configure firewall rules  
- Deploy Apache web server  

---

## ⚙️ Tools Used
- Linux (Ubuntu)
- SSH
- UFW Firewall
- Apache2

---

## 🧪 Steps Performed

### 1. User Management
- Created multiple users (admin, developer, guest)
- Assigned permissions using chmod and chown

### 2. SSH Security
- Disabled root login
- Changed default SSH port
- Configured key-based authentication

### 3. Firewall Setup
- Enabled UFW firewall
- Allowed only required ports (SSH, HTTP)

### 4. Web Server Setup
- Installed Apache2
- Hosted a basic HTML page
- Verified server on browser

---

## 🔐 Security Improvements
- Root login disabled  
- Firewall enabled  
- Limited user access  
- Secure SSH configuration
